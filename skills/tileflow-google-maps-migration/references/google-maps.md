# Google Maps translation notes

- **Coordinates and bounds.** Convert a Google literal to `[point.lng, point.lat]` or a `LatLng` instance to `[point.lng(), point.lat()]` at the boundary. GeoJSON already stores longitude first. For bounds, preserve west/south/east/north and the app's padding. Verify with a known landmark. Google's base tile is 256 pixels and MapLibre's is 512. Subtract 1 from the Google zoom for a similar scale, then compare the visible extent at the same viewport size. [Google coordinates](https://developers.google.com/maps/documentation/javascript/reference/coordinates)
- **Map identity and data.** A Google Cloud map ID selects provider-owned styling. Define the new map and its design locally. Reuse the app's own GeoJSON, style rules, and stable IDs where supported. Track Street View, imagery, Places IDs, and Google-specific overlays independently. A Google place ID cannot identify a Tileflow search result. [Google map IDs](https://developers.google.com/maps/documentation/javascript/map-ids/mapid-over)
- **Selection.** Translate the intent of each `AdvancedMarkerElement`, `InfoWindow`, and listener. Match marker activation to a stable annotation and a text or named popup view. For a map-wide click or camera change, use the installed renderer or wrapper's event payload. Verify focus, dismissal, and teardown in the app. [Google markers](https://developers.google.com/maps/documentation/javascript/advanced-markers/start) · [Google events](https://developers.google.com/maps/documentation/javascript/events)
- **Services.** Identify both the current Google Routes library and any legacy clients. Adapt origins, destinations, modes, route geometry, duration units, and unreachable matrix cells explicitly. Look up current Tileflow traffic and transit coverage before replacing a Google result. Read Search retention and attribution rules before storing results. Keep Static Maps creation on a trusted server and expose the returned image to the browser. [Google Routes library](https://developers.google.com/maps/documentation/javascript/routes/overview) · [Google Maps Static API](https://developers.google.com/maps/documentation/maps-static/overview)
- **Credentials.** Replace the service-specific call site, then decide which of the existing key's consumers remain. Public local map review needs no key. Match hosted calls to the scope, allowed origins, and credential class specified by the corresponding Tileflow guide. Keep server credentials outside browser bundles.
- **Routing cutover.** Verify hosted network and engine availability independently of the SDK exports. If activation is pending or requests return `ROUTING_UNAVAILABLE`, leave the entire screen on its Google map. Test the Tileflow adapter only with local fixtures and leave it undeployed. Review the terms that apply to the agreement. [Google Maps Platform Terms, section 3.2.3(e)](https://cloud.google.com/maps-platform/terms)
